Política de Privacidade

Última atualização: 18 de novembro de 2026.

O Radar de Nichos é uma ferramenta de uso pessoal. Esta política explica quais dados ela acessa e como são tratados.

Dados acessados pelo Google

Com a autorização do próprio dono, a ferramenta usa o escopo da Google Ads API para ler, na conta do Google Ads dele, métricas do Planejador de palavras-chave (volume médio de buscas, tendência e concorrência por país). A ferramenta não cria, altera nem exclui campanhas, anúncios ou configurações.

Onde os dados ficam

Os resultados são gravados somente no computador do dono, em um banco de dados local. A credencial de acesso fica em um arquivo local de configuração e não é enviada a terceiros.

Compartilhamento

Os dados obtidos das APIs do Google não são vendidos, compartilhados, transferidos a terceiros nem usados para publicidade, e são usados apenas para a finalidade descrita acima. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os dados locais podem ser apagados excluindo o banco de dados da ferramenta.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
